# 🌐 Personal Portfolio Website

A responsive personal portfolio website developed using **HTML, CSS, and JavaScript**.

This project is created as part of the **CodeAlpha Frontend Development Internship – Task 3**.

---

## 📌 Project Description

This portfolio website is designed to showcase my personal information, technical skills, projects, and contact details.

The website contains different sections that can be accessed through the navigation menu.

### Sections included:

- 🏠 Home
- 👩‍💻 About Me
- 🛠️ Skills
- 💻 Projects
- 📧 Contact
- 📄 Footer

## 🛠️ Technologies Used

### HTML

HTML is used to create the structure of the portfolio website.

It is used for:

- Navigation
- Headings
- Paragraphs
- Skills
- Projects
- Contact information
- Footer

### CSS

CSS is used to design and style the website.

It is used for:

- Layout
- Colors
- Spacing
- Navigation bar
- Project cards
- Hover effects
- Responsive design

### JavaScript

JavaScript is used to add basic interactivity to the website.

It is used for:

- Page load interaction
- Console message
- Button interaction
